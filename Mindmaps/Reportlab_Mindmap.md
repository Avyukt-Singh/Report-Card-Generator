### Functions

**create_header(s)** -> Paragraph(SCHOOL_NAME, school) ; Paragraph(SCHOOL_ADDR, addr) ; HRFlowable(width="100%", thickness=1.2, color=GOLD, spaceBefore=2, spaceAfter=4) ; Paragraph("ANNUAL PERFORMANCE REPORT", title) ; Paragraph("Session 2026-27 | Class XI | Issued: {DD Month YYYY}", subtitle) ; Spacer(1, 4)

**section_head(text, s)** -> Table([[Paragraph(text, section_head)]], colWidths=[16.4*cm])
  TableStyle: BG NAVY, LEFTPADDING 6, TOPPADDING 3, BOTTOMPADDING 3
  Returns [t, Spacer(1, 4)]

**student_details(res, ranks, s)** -> 3×4 grid Table, colWidths=[3.2, 5, 3.2, 5] cm
  Rows: (Name|value|Roll|value) (Class|value|Section|value) (OverallRank|rk/n|Result|<b>STATUS</b>)
  TableStyle: BG col0 & col2 = LIGHT ; GRID 0.5 lightgrey ; VALIGN MIDDLE ; L/R padding 6 ; T/B padding 4
  Returns [t, Spacer(1, 6)]

**subject_table(res, ranks, s)** -> Header + 5 subject rows + TOTAL row ; colWidths=[4.2, 2.4, 2.4, 2.4, 2, 3] cm ; repeatRows=1
  TableStyle:
  - Header (0,0)–(-1,0): BG NAVY, white text, Helvetica-Bold, size 9, CENTER
  - Body (0,1)–(-1,-2): Helvetica, size 9 ; cols 1..-1 CENTER ; col 0 LEFT
  - Total row (0,-1)–(-1,-1): BG GOLD, white text, Helvetica-Bold
  - GRID 0.5 grey
  - ROWBACKGROUNDS (0,1)–(-1,-2) [white, LIGHT]
  - VALIGN MIDDLE ; T/B padding 4
  - Fail rows (subject total < 33): BACKGROUND #FFCDD2
  Returns [t, Spacer(1, 6)]

**summary_block(res, ranks, s)** -> 6 tiles in one row
  Inner tile(label, value, vc=NAVY): Table with Paragraph(value) + Paragraph(label), colWidths=[2.6*cm], rowHeights=[0.8*cm, 0.4*cm]
  Tiles: TOTAL, AVERAGE, PERCENTAGE, GRADE(vc=GOLD), RANK, STATUS(vc=GREEN if PASS else RED)
  Outer Table([row], colWidths=[2.73*cm]*6)
  TableStyle: BOX 0.5 lightgrey ; INNERGRID 0.5 lightgrey ; VALIGN MIDDLE ; BG LIGHT
  Returns [t, Spacer(1, 6)]

**charts_section(res, s)** -> generate_all_charts(res)
  bar Image: 9×4.8 cm ; pie Image: 7.2×4.8 cm
  Table([[bar, pie]], colWidths=[9.2*cm, 7.2*cm])
  TableStyle: VALIGN MIDDLE ; ALIGN CENTER
  Returns [t, Spacer(1, 6)]

**remarks(res, s)** -> text "<b>Remarks:</b> {remarks}<br/><b>Class Teacher's Note:</b> __________________"
  Panel Table([[Paragraph(text, remark)]], colWidths=[16.4*cm])
  TableStyle: BG #FFF9E6 ; BOX 0.6 GOLD ; L/R padding 8 ; T/B padding 4
  Spacer(1, 8)
  Signature Table 2×3: row0 (empty, LINEABOVE 0.6 black on each) height 0.8*cm ; row1 ["Class Teacher", "Principal", "Parent / Guardian"] height 0.4*cm, ALIGN CENTER, FONTSIZE 8, TEXTCOLOR grey
  colWidths=[5.46*cm]*3
  Spacer(1, 4)
  Footer Paragraph (small): "<i>Computer-generated report card. Generated by Smart Student Report Card Generator.</i>"
  Returns [panel, Spacer(1, 8), sig, Spacer(1, 4), footer]

**generate_pdf(res, ranks, output_path=None)** -> os.makedirs(OUTPUT_DIR, exist_ok=True)
  Default name: ReportCard_{roll}_{name.replace(" ", "_")}.pdf
  SimpleDocTemplate(A4, L/R=2.3, T/B=1.2, title=f"Report Card - {name}", author=SCHOOL_NAME)
  Story order: header → section STUDENT DETAILS → student_details → section SUBJECT-WISE PERFORMANCE → subject_table → section RESULT SUMMARY → summary_block → section PERFORMANCE CHARTS → charts_section → section REMARKS & SIGNATURES → remarks_block
  doc.build(story)
  Cleanup: os.remove(bar_{roll}.png) ; os.remove(pie_{roll}.png)
  Returns output_path
